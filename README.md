# Jubair.fun

Welcome to **Jubair.fun** — a collection of interactive browser games, creative web experiments, and modern frontend projects.

This repository is a playground for building engaging web experiences using modern web technologies. It features classic arcade-inspired games, physics-based challenges, UI/UX experiments, animations, and interactive applications, all designed with clean architecture, smooth performance, and responsive design in mind.

## What You'll Find

🎮 **Browser Games**
- Classic arcade-inspired games
- Physics-based games
- Puzzle and reaction games
- Canvas-powered gameplay
- Leaderboards and scoring systems
- Smooth animations and visual effects

✨ **Interactive Projects**
- Creative UI/UX experiments
- JavaScript animations
- Interactive components
- Fun web applications
- Responsive interfaces

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Canvas API
- Vite

Every project is built to explore new ideas, improve development skills, and deliver fun, polished experiences that run directly in the browser—no installation required.

New games and interactive projects are added regularly.
